# SMART-LECTURE-NOTES-GENERATOR
# 🎓 Smart Lecture Notes Generator

## 📌 Project Description

The **Smart Lecture Notes Generator** is a Text and Speech Analysis application that converts a teacher's lecture audio into useful study notes.

The application uses **Speech-to-Text** to convert audio into text, removes unnecessary words, extracts important keywords, and generates a short summary of the lecture.

This application can help students save time and quickly review important concepts from classroom lectures.

---

## 🎯 Objective

The main objective of this project is to automatically convert spoken lectures into clear and useful notes.

### Main Process

```text
Teacher's Audio
       ↓
Speech-to-Text
       ↓
Text Cleaning
       ↓
Keyword Extraction
       ↓
Summary Generation
       ↓
Lecture Notes
```

---

## ✨ Features

* 🎤 Upload teacher's audio
* 🗣️ Convert speech into text
* 🧹 Remove unnecessary words
* 🔑 Extract important keywords
* 📚 Generate lecture summary
* 📄 Display generated lecture notes
* 🌐 Simple web application interface
* ☁️ Can be run using Google Colab

## 💻 Requirements

You need:

* Google account
* Google Colab
* Internet connection
* Python
* Teacher's audio file (`.wav` or `.mp3`)

---

## ▶️ How to Run

### Step 1: Open Google Colab

Open Google Colab and create a new notebook.

### Step 2: Add the Code

Copy the complete Python application code into a single Colab cell.

### Step 3: Run the Code

Click the **Run ▶** button.

### Step 4: Upload Audio

The application will display an upload option.

Upload a teacher's lecture audio file.

Supported formats:

```text
.wav
.mp
```
